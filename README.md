# Медицинский центр «Здоровье» (Clinic)

Информационная система управления частной медицинской клиникой на C# (Windows Forms + SQLite).

## Основные возможности

1. **Регистратура и записи на приём**:
   - Журнал приёмов с фильтрацией по статусу («Запланирован», «Проведен», «Отменен»), периоду и поисковой строке.
   - Оформление записей с автоматической проверкой расписания врача, графика работы клиники (08:00–19:00) и отсутствия пересечений.
   - Проведение приёма: фиксация диагноза и рекомендаций, расчёт стоимости.
   - Возможность отмены и удаления ошибочных записей.

2. **Учёт врачей и персонала**:
   - Реестр специалистов (ФИО, специальность, телефон, номер кабинета, стоимость приёма).
   - Валидация вводимых данных (корректность стоимости, защита от удаления врачей с активными приёмами).
   - Быстрый поиск по специальности и имени.
   - Кнопка прямого экспорта штата в Excel.

3. **Картотека пациентов**:
   - База данных пациентов (ФИО, дата рождения, контактный телефон, адрес).
   - Валидация корректности дат рождения и защита от удаления пациентов с историей медицинских визитов.
   - Быстрый поиск и кнопка экспорта картотеки в Excel.

4. **Аналитика, отчёты и модуль Excel**:
   - Построение аналитических отчётов за любой период:
     - *Финансовая сводка по врачам и специальностям* (выручка, средний чек, количество приёмов).
     - *Журнал приёмов за период* (детализированный реестр визитов).
     - *Загрузка и продуктивность врачей* (соотношение проведённых, запланированных и отменённых приёмов).
     - *Посещаемость и аналитика пациентов* (активность, общая сумма оплат).
     - *Текущие запланированные приёмы* (ожидающие визиты).
   - **Выгрузка в Excel (.xlsx и .csv)**: автономная генерация файлов OpenXML со стилями, карточками и автоподбором ширины колонок без внешних библиотек.
   - **Загрузка и добавление из Excel**: чтение таблиц `.xlsx` и `.csv`, умное определение колонок и возможность автоматического импорта новых врачей и пациентов в базу SQLite.

5. **Интерфейс**:
   - Однооконная модель работы с **нижним минималистичным HUD-баром** по центру: быстрое переключение между приёмами, врачами, пациентами, отчётами и сводкой без всплывающих окон.
   - Нижняя строка состояния с живыми показателями клиники (число врачей, пациентов, записей на сегодня, общая выручка).
   - Адаптивное масштабирование таблиц и элементов управления при изменении размера окна.

## Запуск проекта

1. Открыть `Clinic.sln` в Visual Studio (2019 / 2022 / 2026).
2. Запустить проект (F5).
3. База данных SQLite (`clinic.db`) создаётся и наполняется демонстрационными данными автоматически при первом запуске.
